# STAMP

Генератор мемов: шаблоны или своё фото, верхний и нижний текст с перетаскиванием, размер шрифта, контур и экспорт в PNG.

## Открыть приложение

Сайт: **https://cryptocbk.github.io/Stamp/**

GitHub хранит код. Сама программа открывается через GitHub Pages по ссылке выше.

## Запуск у себя

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
